# Система обучения сотрудников

Учебный проект для обучения приёмке товара. Наставник назначает курс,
сотрудник изучает материалы и проходит тесты, а наставник видит результаты.

Проект пишем на Go. Первый сценарий — назначение и прохождение одного модуля.

## Запуск

Из корня репозитория с Go 1.26:

```bash
go run ./cmd/employee-training
```

Откройте http://127.0.0.1:8080.

```bash
go test ./...
go vet ./...
```
